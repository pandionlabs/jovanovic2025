# Get model formula

Get model formula

## Usage

``` r
get_formula(x, model_index = 1)
```

## Arguments

- x:

  A dataframe of models from create_models()

- model_index:

  Row number from x to get the formula from

## Value

A model formula

## Examples

``` r
if (FALSE) { # \dontrun{
get_formula(mod_df, 1)
} # }
```
