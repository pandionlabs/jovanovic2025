# Deadwood identities - Create a column that combines species and type of deadwood

Deadwood identities - Create a column that combines species and type of
deadwood

## Usage

``` r
create_deadwood_identities(TreMs)
```

## Arguments

- TreMs:

  A TreMs dataframe

## Value

A TreMs dataframe with a DeadwoodIdentities column

``` r
if (FALSE) { # \dontrun{
```
