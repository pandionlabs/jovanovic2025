# Get model object from a dataframe

Get model object from a dataframe

## Usage

``` r
get_model_object(x, model_index = 1)
```

## Arguments

- x:

  A dataframe of models from create_models()

- model_index:

  Row number from x to get the formula from (optional)

## Value

A model object

## Examples

``` r
if (FALSE) { # \dontrun{
get_model_object(mod_df, 1)
} # }
```
