# Make a count table by decay stage

Make a count table by decay stage

## Usage

``` r
make_count_table_by_decay(TreMs, save_name = FALSE)
```

## Arguments

- TreMs:

  A TreMs dataframe

- save_name:

  Path to save the dataframe

## Value

A count table dataframe

## Examples

``` r
if (FALSE) { # \dontrun{
make_count_table_by_decay(TreMs, save_name = "Count_Table_by_Decay_Stage.csv")
} # }
```
