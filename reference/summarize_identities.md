# Create a summary table for TreMs data

Create a summary table for TreMs data

## Usage

``` r
summarize_identities(x, grouping_variable)
```

## Arguments

- x:

  TreMs dataframe

- grouping_variable:

  variable to be used for grouping

## Value

A summary table

## Examples

``` r
if (FALSE) { # \dontrun{
TreeIdentitiesSummary <- summarize_identities(
TreMs, 
grouping_variable = TreeIdentities2
)
} # }
```
